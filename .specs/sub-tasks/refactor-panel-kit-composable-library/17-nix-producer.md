#### Implementation Notes

- Added `tools/spec-parity` as an unpublished workspace member with `export-schema`, `check-schema`, `decode`, and retained-layout `decode-layout` commands. Schema output is recursively canonicalized before comparison.
- Generated `nix/schema/workspace-spec.schema.json` from `panel-kit-core::spec::WorkspaceSpec` using the `spec-schema` feature; the schema file is committed output, not a hand-authored contract.
- Added `nix/lib/mkWorkspaceSpec.nix`, which normalizes the canonical `WorkspaceSpec` shape, emits `builtins.toJSON`, returns `{ value, json, panel_ids, bindings }`, fills nullable authored fields as `null`, and rejects unknown attrnames with JSON-pointer-like locations.
- Added `nix/lib/validateSchema.nix` for the schemars subset emitted here (`$ref`, objects with required/additionalProperties, arrays/prefixItems, `oneOf` discriminators, constants, strings, booleans, integers, and numbers).
- Added `nix/tests/workspace-spec.nix` as the complete eval-time reference covering the §10.2 top-level surface and every §10.3 content kind, plus `nix/tests/workspace-spec-unknown-attr.nix` for strict unknown-field failure.
- Phase 5 review fix: `mkWorkspaceSpec` now validates each `content.kind` with its exact variant field set before emitting normalized JSON; variant-only extras are rejected instead of being dropped.
- Phase 5 review fix: `DataSource` normalization is branch-specific (`inline` permits only `source`/`value`, `binding` permits only `source`/`id`), and badge nullable fields/click behavior are required explicitly instead of being defaulted.
- Added focused negative eval fixtures: `nix/tests/workspace-spec-content-extra-attr.nix`, `nix/tests/workspace-spec-data-source-ambiguous.nix`, and `nix/tests/workspace-spec-badge-required-null.nix`.
- Phase 5 re-review 1 fix: regenerated `nix/schema/workspace-spec.schema.json` from the post-processed Rust schema; `BadgeSpec.required` now includes `override_color` and `accent_color` while both fields still accept explicit `null`.
- Added `nix/tests/workspace-spec-schema-nullable.nix`, a schema-validator fixture that validates `BadgeSpec` directly: explicit null passes, and removing either nullable color field is rejected.
- Phase 5 re-review 2: no additional strict/Nix metadata check was added in this iteration; the cheap deterministic checks already present are the schema regeneration comparison plus focused required-nullable schema/validator fixtures, while eliminating the remaining repeated field-list metadata would require a broader shared metadata generator rather than a safe final-iteration patch.
